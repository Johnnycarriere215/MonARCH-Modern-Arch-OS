# Docs

| File | Read when |
|---|---|
| `00-BRIEF.md` | **Start here.** What MonARCH is, why it exists, what's in and out of scope |
| `01-DECISIONS.md` | Before proposing anything. If it's decided here, it's settled |
| `02-HARDWARE.md` | Before touching hardware-specific code, or when something breaks |
| `03-ROADMAP.md` | To see what's next and what "done" means |
| `04-TASKS.md` | When you're ready to build. Copy-paste task prompts |
| `05-CHECKLIST.md` | Your own to-do list — things no AI can do |
| `06-RELEASE.md` | Before publishing anything |

`MONARCH.md` in the repo root is the compact version, loaded by AI tools every session. When a decision changes, **update both** `MONARCH.md` and `01-DECISIONS.md` — they must never disagree.
