# Attribution

## Inspiration

MonARCH was inspired by **[Omarchy](https://github.com/basecamp/omarchy)** by David Heinemeier Hansson and 37signals.

Omarchy demonstrated that an Arch + Hyprland desktop could be genuinely beautiful and fast, and several of its ideas shaped MonARCH's design — particularly the `colors.toml` theme schema that restyles every application at once, the timestamped migration pattern for upgrading existing installs, and the discipline of snapshotting before every system update.

**MonARCH is not a fork of Omarchy.** It is an independent project built directly on Arch Linux, with its own configuration, package manifests, CLI, and installer. Where any file has been copied substantially verbatim from Omarchy, that file retains its original MIT copyright notice.

**MonARCH is not affiliated with, endorsed by, or supported by Omarchy, Basecamp, 37signals, or DHH.** Please do not report MonARCH issues to the Omarchy project — they are ours.
