# parchment — backgrounds

**Empty on purpose. No image is committed to this repository without a
recorded licence.**

Drop wallpapers here as `.jpg`, `.jpeg`, `.png` or `.webp`.
`monarch background set` and `monarch background next` pick them up
immediately — there is no index to update.

If an image is going to be **committed**, add a line to the table below first.
"I found it on a wallpaper site" is not a licence, and an ISO that ships an
image we do not have the right to redistribute is a legal problem, not a
tidiness problem.

| File | Source (URL) | Licence | Author |
|---|---|---|---|
| _(none)_ | | | |

Safe sources: your own photographs, CC0 (Unsplash, Pexels — check per image),
and anything explicitly licensed for redistribution. Not safe: Google Images,
Reddit, "wallpaper" apps, or anything AI-generated by a service whose terms
you have not read.
